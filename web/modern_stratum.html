🚀 HOW TO START
WINDOWS
1. DOWNLOAD GMINER (WINDOWS)
2. Create a mine.bat file in the folder.
3. Paste the generated config and run.
LINUX / HIVEOS
1. Install dependencies & Download:
sudo apt update && sudo apt install ...
2. Extract & Grant permission:
tar -xf ... && chmod +x miner
3. Run in background (Screen):
screen -S dibi_mining ./miner ...
